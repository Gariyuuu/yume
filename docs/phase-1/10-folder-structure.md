## Notes

- `packages/room-schema` is the single source of truth for the room object
  shape referenced throughout [02](02-architecture.md)/[03](03-data-model.md)
  — both `apps/web` and `apps/mobile` import it rather than redefining
  types locally, and `supabase/migrations` is kept in sync with it by
  convention (checked in code review, not auto-generated in v1 — a
  schema-to-migration codegen step is a reasonable later improvement, not
  a Phase 1 requirement).
- `packages/game-sdk` defines the *interfaces* (session lifecycle, turn
  validation contract, spectator/reconnect handling) that
  `supabase/functions` game-move validators and each platform's game UI
  both implement against — this is what "modular game SDK so future games
  can be added without rewriting the main application" means concretely.
- `apps/mobile/modules/broadcast-extension` is called out separately
  because it is a distinct Xcode target/App Store binary component, not
  just another RN module — see
  [09-app-store-risk-review.md](09-app-store-risk-review.md) §4.
